# Website Đặt Phòng Khách Sạn - ASP.NET Core

Project nằm trong thư mục `HotelBookingManagementSystem`.

```bash
cd HotelBookingManagementSystem
dotnet restore
dotnet ef database update
dotnet run
```

Xem hướng dẫn đầy đủ, tài khoản demo và connection string trong [HotelBookingManagementSystem/README.md](HotelBookingManagementSystem/README.md).
